# フェーズ完了チェック

いま取り組んでいたフェーズ(README.mdの「今の状態でできること」「次のフェーズ」に書かれている内容)について、以下を順番に行ってください。

1. README.mdに書かれている、そのフェーズで完了しているはずの内容を確認する
2. 実際のコード・動作(必要ならローカルで起動する、/api/health を叩くなど)を見て、本当に完了しているかを検証する。README.mdの記述をそのまま信用しない
3. 完了していれば、README.mdの該当箇所を更新する(できたことを明記し、次にやるべきことも更新する)
4. 未完了の部分やエラー、判断が必要な点があれば、実行せずにここで止めて報告する
5. 最後に、koichiroさん(非エンジニア)向けに、専門用語を避けて次の内容を日本語で報告する
   - 今回のフェーズで何ができるようになったか
   - まだ残っている作業があれば何か
   - 次に何をすればいいか
